# Contributing

Thanks for helping Luna grow!

## Setup

```bash
cp .env.example .env
pip install -r requirements.txt
pytest -q
```

## Rules
- Run `python -m py_compile $(find . -name "*.py")` before PR
- Keep `shayan.txt` header in main files
- English comments only, minimal

## Issues
Use GitHub Issues with `bug` or `feature` label.
